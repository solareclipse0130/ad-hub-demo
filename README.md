# AI 投放中枢 · 演示版

在线体验：https://ad-hub-demo-lemon.vercel.app

给小红书聚光投放优化师用的工作台，核心是「机器起草，人确认」：规则引擎出停投 / 放大 / 补笔记建议，人批准后才执行；按品牌方新笔记表批量起草计划，建完一律暂停；AI 助手只出草稿卡和改动卡，人点了才生效。

本仓库是参照我在实习中做的系统重写的公开演示版，**品牌、人员、数据全部虚构**。我负责需求拆解、流程与规则设计和技术决策，代码在 Claude Code 辅助下完成。

## 页面

| | |
|---|---|
| 01 今日看板 | 昨日指标与环比、各点位卡片、异常检测 |
| 02 建议队列 | 批准 / 改后批准 / 拒绝（必填理由），dry-run 预览请求后再执行 |
| 03 定向 TOP10 | 人群包 × 点位排行，尾部停投候选 |
| 04 批量建计划 | 内容标签 × 人群标签矩阵、照抄模板、跳过原因、每天 30 条上限 |
| 05 规则与映射 | 阈值版本化，改规则建议立即重算 |
| 06 日志与复盘 | 采纳率、审批记录、操作日志 |
| 07 AI 助手 | DeepSeek + 11 个工具，护栏越界直接拒 |
| 08 群消息与盯盘 | 群消息接活、盯盘事件与汇总 |

## 运行

```bash
npm install
echo "DEEPSEEK_API_KEY=sk-..." > .env.local   # 只有 AI 助手需要
npm run dev
npm test
```

可选环境变量：`DEEPSEEK_MODEL`（默认 `deepseek-flash`）。

## 结构

- `src/lib/mock/`：固定种子生成的虚构数据
- `src/lib/engine/`：规则引擎、建计划、护栏、看板取数（纯函数，前后端共用）
- `src/lib/ai/`：助手的工具与文档检索
- `src/app/api/assistant/`：模型调用与工具循环（key 只从环境变量读）
- `src/lib/store.tsx`：演示状态，存在浏览器 localStorage
